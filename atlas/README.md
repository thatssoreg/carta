# CARTA Atlas

This directory is the human-readable projection of CARTA's accepted machine authority.

The Atlas is intentionally empty of entity cards until the first Pyrenean Atlantic ingestion is accepted. STRATA v0.2 defines the projection contract before populating it so the first cards are generated against the corrected post-pilot architecture rather than copied ad hoc from research prose.

See [`../docs/atlas-projection.md`](../docs/atlas-projection.md).

Expected card families:

- `ecosystems/`
- `countries/`
- `regions/`
- `appellations/`
- `grapes/`
- `producers/`
- `people/`
- `wines/`
- `institutions/`
- `practices/`
- `classifications/`
- `historical-events/`
- `indexes/`

The structured data is authoritative when an Atlas page and a machine record disagree. The long-term goal is to generate factual sections from accepted records so that divergence is rare and visible.
